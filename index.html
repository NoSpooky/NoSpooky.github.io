Modificadores de Acceso y Encapsulamiento de Clases | C# 5.0

Encapsulamiento de Clases

El encapsulamiento es uno de los pilares fundamentales de la programación orientada a objetos (POO). Consiste en agrupar en una misma clase los datos (variables o atributos) y los métodos (funciones) que operan sobre esos datos, restringiendo el acceso directo a algunos de los componentes desde fuera de la clase. Esto protege la integridad del objeto evitando que datos internos sean modificados de manera incorrecta o no autorizada.

Modificadores de Acceso

Los modificadores de acceso en C# 5.0 especifican la visibilidad y accesibilidad de los miembros dentro del programa. Los principales son:

public: El miembro es accesible desde cualquier otra clase o código sin restricciones. 

public class Persona
{
    // Accesible desde cualquier parte del programa
    public string nombre; 
}

private: El acceso está estrictamente limitado a la misma clase donde se declaró. Es el más restrictivo para el encapsulamiento. 

public class CuentaBancaria
    {
    // Solo se puede modificar y leer desde dentro de esta misma clase
    private double saldo; 
}

protected: El miembro es accesible dentro de su propia clase y por cualquier clase derivada (herencia). 

public class Vehiculo
{
    // Accesible aquí y en clases hijas que hereden de Vehiculo
    protected string numeroChasis; 
}

internal: El acceso se limita exclusivamente al ensamblado actual (al proyecto de C# actual), permitiendo que clases del mismo proyecto accedan a él. 

internal class ConfiguracionApp
{
    // Accesible solo dentro del mismo proyecto/ensamblado
    internal string servidorConexion; 
}
